# KM Energy

Концептуально-онтологическая модель аналитического контура энергетического моделирования.

Репозиторий предназначен для публикации OWL-ядра, SPARQL-запросов к компетентностным вопросам и примеров данных, сопровождающих исследование каузально-когнитивного представления результатов оптимизационного моделирования энергетических систем.

## Статус

Материалы готовятся к публикации. Состав онтологии и её соответствие концептуальной схеме уточняются. Зафиксированный релиз приложения к статье пока не выпущен.

Планируемое пространство имён: `https://w3id.org/km-energy/ontology#`. Регистрация в w3id ещё не завершена.

## Планируемый состав

- `ontology/` — OWL-ядро в RDF/XML и Turtle.
- `queries/` — шесть SPARQL-запросов, соответствующих компетентностным вопросам.
- `examples/` — пример RDF-данных и результаты выполнения запросов.
