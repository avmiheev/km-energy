# SPARQL-запросы к компетентностным вопросам

Шесть запросов реализуют компетентностные вопросы раздела 1.2 статьи. Они выполняются над объединённым графом [онтологии](../analytics-core.ttl) и [примера данных](../article-example.ttl). Файл `cxl-example.ttl` для этих запросов не требуется. Удалённая SPARQL-служба не нужна; разрешение адресов w3id через Интернет при выполнении не используется.

## Вопросы и результаты примера

| № | Компетентностный вопрос | Файл | Ожидаемый результат |
|---|---|---|---|
| КВ1 | Какие аналитические факторы связаны с выбранным выходным показателем? | [cq1_factors.rq](cq1_factors.rq) | 2 строки: налог на CO₂ и рыночная цена для прибыли. |
| КВ2 | Какие факторы формируют наибольший вклад в неопределённость результата? | [cq2_rank_st.rq](cq2_rank_st.rq) | 2 строки по убыванию ST: рыночная цена (0,52), налог на CO₂ (0,41). Ранжируются только имеющиеся оценки для прибыли. |
| КВ3 | Какие факторы обладают выраженным модельно-имплицированным направленным эффектом? | [cq3_strong_effects.rq](cq3_strong_effects.rq) | 2 строки при модуле CE не менее 0,4: рыночная цена (0,51), налог на CO₂ (-0,44). Знак эффекта сохраняется. |
| КВ4 | Какие связи включаются в каузально-когнитивную карту при заданных порогах ST и модуля CE? | [cq4_selected_edges.rq](cq4_selected_edges.rq) | 4 строки: бюджет - использование бюджета; цена - прибыль; цена - выручка; налог - прибыль. |
| КВ5 | К какому классу матрицы ST×CE относится оценка пары «аналитический фактор - выходной показатель»? | [cq5_classification.rq](cq5_classification.rq) | 5 строк: 2 `Critical`, 2 `Moderate`, 1 `Uncertainty`; во всех строках `matches=true`. |
| КВ6 | Какие результаты анализа могут быть использованы при формировании объясняющего отчёта и поддержке принятия решений? | [cq6_report.rq](cq6_report.rq) | 5 строк: 4 оценки проходят отбор, 1 исключена; отсутствующие метаданные остаются незаполненными. |

КВ1-КВ3 используют эксперимент `ex:italyExperiment` и показатель `ex:profit`. Параметры задаются в блоках `VALUES`. КВ4 использует карту `ex:demoMap`, КВ5 - указанный эксперимент, КВ6 - отчёт `ex:demoReport`. При работе с другими данными замените соответствующие идентификаторы.

В демонстрационной карте отбор строгий: ST больше 0,4 и модуль CE больше 0,3; равенство порогу не проходит отбор. КВ3 использует отдельный включающий порог для модуля CE. Классификация КВ5 и отбор рёбер КВ4 выполняют разные функции. КВ4 возвращает подходящие оценки; поле `actualEdge` позволяет проверить наличие записанного ребра. В КВ6 поля `selected` и `hasEdge` различают прохождение условий отбора и фактическое присутствие ребра.

## Запуск

Скачайте репозиторий целиком, сохранив структуру каталогов. В отдельном Python-окружении установите использованные версии библиотек:

```sh
python -m pip install rdflib==7.6.0 pyparsing==3.3.2
```

Из корня репозитория выполните:

```sh
python ontology/queries/run_queries.py
```

Скрипт загружает локальные файлы, выполняет все шесть запросов и выводит JSON. Пути определяются относительно скрипта. Проверено с Python 3.12.14, RDFLib 7.6.0 и pyparsing 3.3.2; суммарный граф содержит 1096 троек. Число строк по запросам: **2, 2, 2, 4, 5, 5**.

Полный результат приведён в [expected-results.json](expected-results.json). Значения RDF-термов записаны в нотации N3 с сохранением типа и языковой метки; `null` означает несвязанную переменную. Порядок строк задаётся `ORDER BY` в запросах. Запросы можно выполнять и в другом средстве с поддержкой SPARQL 1.1, загрузив оба файла в один граф по умолчанию; логический вывод OWL не требуется.

## Границы примера

Данные воспроизводят пять округлённых пар из редакции статьи rev01. Это пример представления и извлечения результатов, а не полный набор сценариев и не новые расчёты января/июля. Пороги карты выбраны для демонстрации и не заявляются как восстановленные настройки рисунка статьи. Вес демонстрационного ребра равен CE.

Запросы не рассчитывают индексы Соболя и направленные эффекты и не подтверждают причинные предпосылки модели. В КВ6 отсутствующие сведения о методе, нормировке и расчётном контрасте не подставляются. Наличие необязательных полей контраста не означает, что в статье выполнены интервенционные эксперименты.
