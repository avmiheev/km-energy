# KM Energy

Онтология аналитического контура для интерпретации результатов оптимизационного моделирования энергетических систем. Версия приложения **0.3.0** согласована с редакцией статьи Козлова и Михеева **rev05** от 23 сентября 2026 г.

Пример содержит **484 пары «фактор - показатель»**: 22 фактора и 11 показателей отдельно для января и июля 2013 г. Перенесены сохраненные оценки расчетных материалов без повторного оценивания и округления. Неопределенные июльские оценки мощности СЭС представлены отдельно, а не заменены нулями.

Правила классификации соответствуют таблице 1 rev05. Строгий фильтр `st > 0.1 && ABS(ce) > 0.3` формирует 20 январских и 16 июльских ребер; 11 пар общие. Распределение категорий и статусов соответствует таблице 6. `No_ST` и отсутствие определенной оценки не являются дополнительными категориями влияния.

## Запуск

Из корня репозитория в выбранном Python-окружении:

```sh
python -m pip install -r ontology/requirements.txt
python ontology/generate_example.py --check
python ontology/queries/run_queries.py --check
python ontology/validate.py
python ontology/validate_alignment.py
```

Проверки выполняются локально. Они проверяют структуру RDF, правила, запросы и формирование карт по сохраненным метрикам. Исходные сценарные массивы в приложение не включены; оптимизация, индексы Соболя и регрессии заново не вычисляются. Проверка формального представления не является проверкой точности исходных статистических оценок или доказательством причинности в реальной энергосистеме.
